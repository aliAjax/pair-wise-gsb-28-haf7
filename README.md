# 配送排班 · 可拖拽班次板

- 行业：物流
- 技术栈：React、Vite、TypeScript、dnd-kit、zustand
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

把原来“下拉框改司机”改成**可拖拽的班次板**：待分配订单按取货时段分组，拖入早/中/晚班司机列即可排班；已发车订单可拖给下一班（等同交接，必须留原因），也能拖回原司机班次。

## 排班规则（领域层，纯函数）

规则集中在 `src/domain/`，不依赖 React 与存储，可单独单测：

1. **按取货时段入班次**：待分配池按取货开始时间分早班 06–14 / 中班 14–22 / 晚班 22–06（晚班跨零点）。
2. **重叠时段只能接一单**：同一司机班次内取货时段重叠即 `overlap` 硬冲突（晚班自动按次日比较）。
3. **冷链必须有保温箱**：冷链订单交给无保温箱司机即 `cooler` 硬冲突。
4. **单班总重/总时长**：超出载重或作业时长上限为软冲突（`weight` / `duration`），订单先进**待放行**，由调度点“强制放行”。
5. 硬冲突（重叠、冷链）不可放行，只能退回待分配重排；放行前会按最新容量重新评估。

## 发车交接

已排班订单点“确认发车”；已发车订单拖向任意司机列（或点“交接下一班”）弹出交接单：

- 必留**原司机、原因、新司机**，写入左侧交接记录；
- 确认后**旧司机容量当场释放**，新司机承担该单负载；
- 新司机存在时段/冷链硬冲突时禁止交接，超重/超时给警示但不拦（由调度担责）。

## 受阻信息

待放行车道的每张受阻卡列出：**订单号、目标司机、取货时段、超重 kg / 超时分钟**及与哪一单时段冲突。

## 分层结构

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 数据 | `src/data/` | zustand store、localStorage 持久化（key `hxwlfront-14-shift-board-v2`）、演示种子数据 |
| 校验 | `src/domain/` | 班次定义、时段重叠、容量/冷链/时长校验，全部为纯函数 |
| 交互 | `src/components/` | dnd-kit 班次板、订单卡、交接弹窗、交接记录、新增表单 |

数据保存在浏览器 localStorage，**页面重开后排班、待放行和交接记录都能续接**；右上角“恢复演示数据”可一键还原。
