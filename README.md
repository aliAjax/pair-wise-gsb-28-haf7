# 配送任务拖拽排班（班次板）

- 行业：物流
- 技术栈：React、Vite、TypeScript、Ant Design、dnd-kit、zustand
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 测试：`npm test`（纯逻辑 / 数据层 / 重开续接，共 20 项）

把待分配订单按取货时段拖给司机班次的排班台，替代下拉框改派。

## 规则

- **拖拽排班**：待分配订单拖入班次列即排班；已排班订单可跨班拖动改派，也可拖回待分配池（已发车除外）。
- **重叠时段**：同一班次内取货时段重叠只能接一单（端点相接不算重叠），冲突为硬性受阻。
- **冷链**：冷链订单只能由配备保温箱的司机承接，违反为硬性受阻。
- **待放行**：单班总重或总时长超限属软冲突，订单先挂到该班「待放行」，由调度员确认放行或退回。
- **发车交接**：已发车订单可「交接下一班」（按钮或拖到目标班次），记录原司机、交接原因、新司机；交接成功后原班容量当场释放，受阻则留在原班并登记。
- **受阻清单**：每次受阻记录订单、司机/班次、取货时段与超重/超时长明细，可一键放行或核销，历史可回看。
- **持久化**：全部状态存于浏览器 localStorage，刷新或重开页面后排班、受阻与交接记录原样续接。

## 分层

```
src/
  types.ts               领域模型（订单/司机/班次/受阻/交接）
  lib/time.ts            时间工具（纯函数）
  lib/validation.ts      校验层：排班冲突计算（纯函数，可单测）
  lib/violationText.ts   违规文案（纯函数）
  store/scheduleStore.ts 数据层：zustand + localStorage 持久化与领域动作
  components/            交互层：拖拽班次板、待分配池、受阻清单、交接/新增弹窗
  App.tsx                组装：DndContext、落子反馈、布局
test/                    esbuild + node 的冒烟测试（不依赖浏览器）
```
